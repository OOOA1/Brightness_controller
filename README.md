# Brightness Voice Control 0.1

Программное затемнение до трёх экранов в Windows 11. У каждого экрана отдельный слой; аппаратная яркость подсветки не меняется. Управление через трей или голосом на русском языке. Распознавание Vosk и ответы Windows SAPI работают локально.

## Запуск из исходников

Требуется **Windows 11 x64, Python 3.11 или 3.12 x64**, рабочий микрофон и системный трей. Откройте PowerShell в папке проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python download_model.py
python main.py
```

Если PowerShell запрещает активацию, используйте `.\.venv\Scripts\python.exe` вместо `python` в последних трёх командах. Загрузка модели нужна один раз и требует интернета; после неё приложение не передаёт аудио и не обращается к сети. Модель лежит в `models/vosk-model-small-ru-0.22` (около 45 МБ в архиве). [Страница модели](https://alphacephei.com/vosk/models).

Левой кнопкой на иконке трея открываются ползунки; правой — меню. В настройках назначьте названия физическим дисплеям, выберите микрофон и проверьте голосовой ответ. При первом запуске названия распределяются слева направо. Голосовая команда начинается со слова «Компьютер»: «Компьютер, яркость левого монитора 10 процентов», «Компьютер, все мониторы на максимум», «Компьютер, сделай темнее». После ключевого слова можно произнести команду отдельной фразой в течение 7 секунд. Если уверенность распознавания низкая, приложение спросит подтверждение; ответьте «Да» или «Нет» либо нажмите кнопку в уведомлении в течение 9 секунд.

Если Windows не имеет установленного русского голоса SAPI, голосовой ответ может звучать другим голосом. Установите русский речевой пакет в параметрах Windows. При недоступном микрофоне иконка и ручные ползунки продолжают работать. Файл настроек: `%APPDATA%\BrightnessVoiceControl\config.json`.

### Если экран оказался слишком тёмным

Завершите прежний процесс `BrightnessVoiceControl.exe` или `python.exe` через Диспетчер задач, затем в папке проекта выполните `python main.py --reset-brightness` (для собранной версии: `dist\BrightnessVoiceControl.exe --reset-brightness`). Эта команда сбрасывает сохранённую яркость на 100% для следующего запуска и сразу завершает работу. После неё запустите приложение обычным способом. Можно также удалить значения из раздела `brightness` в файле конфигурации.

## Сборка EXE

После установки зависимостей и модели выполните:

```powershell
.\build.ps1
```

Исполняемый файл появится в `dist\BrightnessVoiceControl.exe`; модель встроена в него. Для автозапуска включите опцию в настройках уже запущенного EXE (запись в HKCU Run указывает на его текущий путь). При перемещении EXE настройте автозапуск снова.

## Проверка парсера

```powershell
python -m unittest discover -s tests -v
```

Слои показываются поверх обычного рабочего стола. Защищённые окна UAC, эксклюзивные полноэкранные приложения и видеовыходы, обходящие композицию рабочего стола, могут отображаться поверх слоя. Монитор отключается или подключается — список экранов обновляется; имена привязаны к идентификаторам дисплеев Windows. Изменение идентификатора после перестановки портов может потребовать переназначения в настройках. Полное испытание трёх мониторов, микрофона и собранного EXE необходимо выполнить на Windows 11.
