# Brightness Voice Control 1.1 — исходный код

Приложение для Windows 11 x64: программное плавное затемнение всех подключённых мониторов, ползунки в трее, локальное распознавание русской речи Vosk и ответы через Windows SAPI5. Аудио не сохраняется и не отправляется в интернет.

## Запуск на Windows

Нужны Python **3.11 или 3.12 x64**, микрофон и Windows 11. Распакуйте архив и откройте PowerShell в папке `brightness_voice_control`:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python download_model.py
python main.py
```

Если активация PowerShell запрещена, запускайте `.\.venv\Scripts\python.exe` вместо `python`. Модель скачивается один раз. Для ручной установки скачайте [vosk-model-small-ru-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) и распакуйте в `models/vosk-model-small-ru-0.22`.

При обновлении существующего окружения выполните `python -m pip install -r requirements.txt`. Зависимость `numpy` нужна также для проверки микрофона. Настройки предыдущей версии остаются в `%APPDATA%\BrightnessVoiceControl\config.json`; программа автоматически преобразует схему 2 в схему 3. Рекомендуется сохранить копию этого файла перед обновлением.

## Использование

При первом запуске мастер предложит назвать обнаруженные мониторы, выбрать микрофон, ключевую фразу и голос ответа. По умолчанию обращение — «Компьютер». В настройках на странице «Голос» можно изменить фразу, проверить её до сохранения, настроить сигнал, ожидание команды (3–10 секунд), голос Windows и прослушать пример. Тишина после обращения закрывает плашку без сообщения об ошибке.

Примеры: «Компьютер, яркость тридцать процентов» меняет все активные экраны; «Компьютер, монитор четыре на двадцать» — четвёртый экран; «Компьютер, игровой на десять» использует пользовательское имя или голосовой псевдоним. Можно произнести обращение и команду отдельно. При одном мониторе общий ползунок скрыт, при большом числе список прокручивается. Подключение и отключение экранов обновляет интерфейс без перезапуска.

Левый клик по значку трея открывает ползунки, правый — меню. Ползунок действует сразу, голос и профили запускают плавный переход. Профили связаны с идентификаторами дисплеев и переживают их переименование и временное отключение. В настройках также доступны расписание и уведомления.

## Сборка EXE и установщика

После установки зависимостей и модели:

```powershell
.\build.ps1
```

PyInstaller создаст `dist\BrightnessVoiceControl.exe` с моделью внутри. Если установлен Inno Setup 6, будет создан `dist\BrightnessVoiceControl-Setup-1.1.exe`. Установщик не требует отдельного Python. Настройки сохраняются при обновлении и удалении программы.

Автозапуск не открывает настройки. Повторный запуск открывает панель; `--settings` открывает настройки. `--reset-brightness` удаляет сохранённую яркость и завершает процесс; сначала закройте работающий экземпляр.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Конфигурация записывается атомарно с резервной копией `config.backup.json`. Логи с ротацией находятся в `%APPDATA%\BrightnessVoiceControl\logs`; аудио в них не записывается.

Автоматические тесты проверяют parser, строгий критерий wake, переходы состояний, миграцию и динамическое именование. Реальное распознавание, длительная проверка ложных пробуждений, несколько физических экранов, DPI, hot-plug, сон Windows, доступность SAPI голосов и сборка установщика требуют запуска на Windows 11. Защищённый рабочий стол UAC, эксклюзивный полноэкранный режим и отдельные аппаратные видеослои могут перекрывать программный слой. Подсветка монитора аппаратно не меняется; при 0% слой остаётся слегка прозрачным.
